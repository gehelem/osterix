# Java Version Compatibility Fix for Capacitor 7.4.3

## Problem
When running `npx cap sync android`, Capacitor regenerates `capacitor.build.gradle` with Java 21 settings, which conflicts with Java 17 availability on the build machine.

Error:
```
error: invalid source release: 21
```

## Solution
A permanent override mechanism has been implemented using Gradle's `apply from` directive.

## Files Modified/Created

### 1. `android/app/java-version-override.gradle` (NEW)
This file contains the Java 16 configuration that overrides any Capacitor-generated settings:

```gradle
android {
    compileOptions {
        sourceCompatibility JavaVersion.VERSION_16
        targetCompatibility JavaVersion.VERSION_16
    }
}

tasks.withType(JavaCompile).configureEach {
    sourceCompatibility = JavaVersion.VERSION_16.toString()
    targetCompatibility = JavaVersion.VERSION_16.toString()
}
```

### 2. `android/app/build.gradle` (MODIFIED)
Added import of the override file AFTER capacitor.build.gradle is applied:

```gradle
apply from: 'capacitor.build.gradle'

// IMPORTANT: Force Java 16 compatibility for Capacitor 7.4.3
// This overrides any Java 21 settings that may be in capacitor.build.gradle
apply from: 'java-version-override.gradle'
```

### 3. `android/app/capacitor.build.gradle` (MODIFIED)
Changed VERSION_21 to VERSION_16:

```gradle
android {
  compileOptions {
      sourceCompatibility JavaVersion.VERSION_16
      targetCompatibility JavaVersion.VERSION_16
  }
}
```

## How It Works

1. **capacitor.build.gradle** is auto-generated by Capacitor and contains Java 21
2. **app/build.gradle** applies the capacitor.build.gradle file
3. **app/build.gradle** then applies **java-version-override.gradle** which overrides the Java version
4. The override happens AFTER capacitor configuration, so it takes precedence

## Persistence

This fix will persist even when you run:
```bash
npx cap sync android
```

Because:
- `java-version-override.gradle` is a custom file NOT generated by Capacitor
- It's imported in `app/build.gradle` which is NOT auto-generated
- The import statement will remain in place after Capacitor sync

## If Capacitor Regenerates app/build.gradle

In the unlikely event that Capacitor regenerates `app/build.gradle`:

1. Re-add the import line after `capacitor.build.gradle`:
   ```gradle
   apply from: 'java-version-override.gradle'
   ```

## Compatibility Notes

- **Java Version**: 16 (matches Capacitor 7.4.3 requirements)
- **Why 16?**: Capacitor uses Java 16+ features (pattern matching in instanceof, switch expressions)
- **Why not 21?**: Not needed for Capacitor 7.4.3, and Java 17 is the installed version

## Future Upgrades

When upgrading to Capacitor 8.x or higher:
1. Check if they support Java 11 or allow Java 21
2. Update both files to match new requirements
3. Or remove the override if no longer needed

## Build Verification

After this fix:
```bash
./gradlew clean assembleDebug
# Should complete successfully in ~4-5 seconds
# APK will be created at: android/app/build/outputs/apk/debug/app-debug.apk
```

## Troubleshooting

If you still see `error: invalid source release: 21`:

1. Clear gradle cache:
   ```bash
   ./gradlew clean
   rm -rf .gradle
   ```

2. Verify the override file exists:
   ```bash
   cat android/app/java-version-override.gradle
   ```

3. Check app/build.gradle imports the override:
   ```bash
   grep "java-version-override" android/app/build.gradle
   ```

4. Try full rebuild:
   ```bash
   ./clean-android.sh all
   npm install
   ./build-android.sh development apk
   ```
