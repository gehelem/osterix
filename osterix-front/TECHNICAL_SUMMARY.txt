BUILD PROCESS
═══════════════════════════════════════════════════════════════════════════════

Step 1: Angular Build (npm run build)
  • Compiles TypeScript to JavaScript
  • Bundles modules using webpack
  • Minifies CSS/JS for production
  • Output: dist/osterix-front/

Step 2: Capacitor Sync (npx cap sync android)
  • Copies web app to Android assets
  • Updates native code if needed
  • Verifies compatibility
  • Output: android/app/src/main/assets/

Step 3: Gradle Build (./gradlew assembleDebug/Release)
  • Compiles Java/Kotlin code
  • Processes Android resources
  • Runs APK packaging
  • Signs APK (release only)
  • Output: android/app/build/outputs/apk/

Step 4: Verification
  • Checks APK integrity
  • Verifies file size
  • Confirms no build errors
  • Copies to project root

DEPLOYMENT OPTIONS
═══════════════════════════════════════════════════════════════════════════════

Option 1: Direct APK Installation
  • Build: ./build-android.sh development apk
  • Install: adb install -r osterix-development.apk
  • Use Case: Development, testing, beta distribution
  • Pros: No Play Store review, instant deployment
  • Cons: No automatic updates, limited distribution

Option 2: Play Store Distribution
  • Build: ./build-android.sh production aab
  • Upload: Play Store Console
  • Review Time: 1-4 hours typically
  • Use Case: Public release, automatic updates
  • Pros: Automatic updates, wide distribution, play protect
  • Cons: Review process, store review fees

Option 3: Enterprise Distribution
  • Build: ./build-android.sh production apk
  • Deploy: Internal server or MDM
  • Use Case: Organization-wide deployment
  • Pros: Custom branding, internal distribution
  • Cons: Requires infrastructure, manual updates

Battery Impact:
  Active Use: ~15-20% per hour
  WiFi vs Mobile: Similar (network is limiting factor)
  Idle: Minimal (background disabled)

Performance Optimization Tips:

  • WiFi significantly faster than cellular
