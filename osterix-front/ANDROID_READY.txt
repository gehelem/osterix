🚀 QUICK START

1. Install dependencies:
   $ npm install

2. Build development APK:
   $ ./build-android.sh development apk

3. Install on device:
   $ adb install -r osterix-development.apk

4. Configure server connection in app:
   - Host: <your-server-ip>
   - Port: 9624
   - Secure: OFF

5. Start observing! 🔭

⚠️ IMPORTANT NOTES

1. Server Connection:
   - App requires manual server configuration on first launch
   - Server IP, port, and security settings must be entered
   - Works on local network without HTTPS (development)
   - Requires HTTPS/reverse proxy for remote access

2. Permissions:
   - Camera, Location, and Storage permissions are optional
   - App handles permission denial gracefully
   - Some features may be disabled without permissions

3. Network:
   - App requires active connection to OST server
   - No offline mode or data caching
   - Slow networks may cause timeouts

4. Security:
   - Local network connection is unencrypted (ws://)
   - For remote access, use reverse proxy with SSL (wss://)
   - Never commit keystore or credentials to git
