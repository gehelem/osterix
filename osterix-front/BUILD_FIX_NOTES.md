# Android Build Fix Notes

## Problem
The initial Android build failed with the error:
```
error: invalid source release: 21
```

This was caused by a Java version compatibility issue between:
- Capacitor 7.4.3 (which requires Java 16+ for pattern matching and switch expressions)
- The build configuration specifying Java 21 when only Java 17 was available
- Gradle 8.1.1 (not fully compatible with compileSdk 35)

## Root Causes
1. **capacitor.build.gradle** (auto-generated) set `VERSION_21` as default
2. Capacitor core library uses Java 16+ language features (pattern matching in instanceof, switch expressions)
3. Multiple build.gradle files had inconsistent Java version settings
4. Gradle configuration needed updates for SDK 35 compatibility

## Solution Implemented

### 1. Updated Java Version Targets
Changed all build.gradle files to use **Java 16** instead of 11 or 21:

- **android/build.gradle** - Root configuration
- **android/app/build.gradle** - App module
- **android/app/capacitor.build.gradle** - Capacitor config (modified with comment)
- **android/capacitor-cordova-android-plugins/build.gradle** - Cordova plugins
- **node_modules/@capacitor/android/capacitor/build.gradle** - Capacitor library

### 2. Updated gradle.properties
```gradle
# Increase JVM memory
org.gradle.jvmargs=-Xmx4096m

# Enable parallel builds
org.gradle.parallel=true

# Suppress SDK 35 warnings
android.suppressUnsupportedCompileSdk=35

# Set Java home
org.gradle.java.home=/usr/lib/jvm/java-17-openjdk-amd64
```

### 3. Gradle Configuration
Added to root **build.gradle**:
```gradle
allprojects {
    tasks.withType(JavaCompile).configureEach {
        sourceCompatibility = JavaVersion.VERSION_16
        targetCompatibility = JavaVersion.VERSION_16
    }
}
```

## Java Version Requirements
- **Required**: Java 17 or higher (for Capacitor 7.4.3)
- **Configured for**: Java 16 source/target (maximum compatible with current Gradle)
- **Tested with**: OpenJDK 17.0.16

Java 16 features used by Capacitor:
- Pattern matching in instanceof
- Switch expressions
- Records (Java 14+)

## Important Notes

1. **Do not edit capacitor.build.gradle directly** - it's auto-generated by Capacitor
   - However, the Java version settings have been overridden with a comment for future reference
   - If you run `npx cap sync android`, the file will be regenerated but the Java 16 setting should persist

2. **The node_modules change** - If you reinstall dependencies with `npm install`, you'll need to re-apply the Java 16 fix to `node_modules/@capacitor/android/capacitor/build.gradle`

3. **Gradle version compatibility** - Gradle 8.1.1 works but shows warnings about SDK 35. Consider upgrading to Gradle 9+ when available.

4. **Java version constraint** - Java 16 is the maximum compatible with Android Gradle plugin 8.1.1 while supporting Capacitor's language features.

## Alternative: Update Capacitor/Gradle (Future)

When ready to upgrade:
1. Update @capacitor/android to 8.x or higher
2. Update Android Gradle plugin to 8.5+
3. Update Gradle to 9.0+
4. Then can use Java 17/21 directly
